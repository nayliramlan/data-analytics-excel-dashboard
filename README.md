# SUPERSTORE HQ Data Analysis (Interactive Dashboard by Microsoft Excel)
## Project Objective
The objective was to analyse financial and operational performance and develop an interactive excel dashboard for easier communication of key findings between the directors and stakeholders
## Dataset
<a href= "https://github.com/nayliramlan/data-analytics-portfolio/blob/main/SUPERSTORE%20HQ%20DASHBOARD.xlsx">Dataset Source</a>
## Questions
- Which year recorded the highest profit and how much was the recorded profit?
- What are the total profit made in each year from 2012 to 2015?
- Which segment contributes to the highest profit?
- Which is the best and worst performing regions?
- Identify the top 3 categories which the company should focus on to improve the annual profits
- Are there any categories which are not bringing in any profits to the company?
- What is the distribution of orders across shipping modes?
## Process
- Verify the data and perform data cleaning for any missing values or anomalies
- Standardised all data to ensure all the data are consistent 
- Created pivot tables for different values to analyse profitability across years, segments, regions, categories and shipping modes
- Convert key findings into charts and KPI summaries
- Merge all pivot tables and chart created into one dashboard and add slicers for dynamic filtering
## Tools Used
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data visualisation
- Dashboard Development

## Findings
- 2015 yielded the greatest profit with a profit of RM102,131.99
- The profit has been increasing every year since 2012 until 2015. Rising from RM 38,560.32 to RM62,806.31 then 80,162.56 and reaching RM 102,131.99
- The segment that contributes to the highest profit is consumer segment
- The best performing region is Asia Pacific with 30.18% while worst performing region being Africa recording only 5.86% of sum of profit
- Phones, Copiers and Appliances were identified as the top three categories by profit contribution, highlighting potential areas for continued business focus.
- Tables recorded negative profitability and was identified as an underperforming categort requiring further investigation
- Ship mode is dominated by standard class with a percentage of 60% followed by second class of 20%. Next is first class with 15% and the least being same day shipping mode with 5%
