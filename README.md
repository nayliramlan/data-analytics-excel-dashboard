# SUPERSTORE HQ Data Analysis (Interactive Dashboard by Microsoft Excel)
## Project Objective
Superstore HQ wants to highlight the key findings of their financial analysis so that the directors and stakeholders can review them in the upcoming yearly review
## Data used
<a href= "https://github.com/nayliramlan/data-analytics-portfolio/blob/main/SUPERSTORE%20HQ%20DASHBOARD.xlsx">Dataset</a>
## Questions
- Which point in the year yielded the greatest profit and how much was the recorded profit?
- What are the total profit made in each year from 2012 to 2015?
- Which segment contributes to the highest profit?
- Which is the best and worst performing regions?
- Identify the top 3 categories which the company should focus on to improve the annual profits
- Are there any categories which are not bringing in any profits to the company?
- What are the respective percentages for each of this ship mode?
## Process
- Verify the data and perform data cleaning for any missing values or anomalies
- Ensure all the data are consistent 
- Created pivot tables for different values and readings
- Merge all pivot tables and chart created into one dashboard and add slicers for easier navigations
